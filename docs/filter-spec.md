# Filter Spec

このドキュメントは、写真フィルターの仕様書です。  
企画、実装、調整の共通参照として使ってください。

## 1. フィルター一覧

現在のフィルターは次の 5 つです。

- `None`
- `Hot`
- `Cold`
- `Invert`
- `Sepia`

## 2. 基本ルール

フィルターは 2 か所に作用します。

1. 撮られた元オブジェクト
2. 配置された写真コピー

つまり「撮った瞬間」と「貼った後」の両方で効果があります。

## 3. フィルターごとの仕様

### `None`

意味:

- 通常撮影

元オブジェクト:

- 特殊効果なし
- 撮影済みっぽい見た目変化のみ

写真コピー:

- 元の性質をできるだけ維持する

### `Hot`

意味:

- 熱、燃焼、危険化

元オブジェクト:

- 敵: 無効化
- `PhotoSource` / `Pickup` 系: 無効化
- 見た目: 赤熱色

写真コピー:

- `Hazard` 化
- 前景に置かれる
- 赤系の見た目になる

### `Cold`

意味:

- 凍結、固定、足場化

元オブジェクト:

- 敵: 凍結して停止
- `Hazard` 系ギミック: 無効化
- 見た目: 青白い色

写真コピー:

- `Solid` 化
- 前景に置かれる
- 氷っぽい見た目になる

### `Invert`

意味:

- 敵対関係の反転

元オブジェクト:

- 敵: 敵対を失って停止
- 見た目: 明るい反転色

写真コピー:

- 敵由来なら `Ally` 化
- 敵以外は `Solid`
- 前景に置かれる

### `Sepia`

意味:

- 時間巻き戻し

元オブジェクト:

- 敵: 復活状態へ戻る
- 敵: 凍結解除
- 敵: 移動位相を少し巻き戻す
- ギミック: 再有効化
- 見た目: セピア色

写真コピー:

- `Solid`
- 前景に置かれる
- セピア色になる

## 4. 現在の入力

- `1`: `None`
- `2`: `Hot`
- `3`: `Cold`
- `4`: `Invert`
- `5`: `Sepia`
- `C`: 順送り切り替え

## 5. 現在の見た目

撮影フレーム:

- `None`: 白
- `Hot`: 赤
- `Cold`: 青
- `Invert`: 灰白
- `Sepia`: 茶系

画面内 UI:

- 左上に現在フィルター名
- 効果説明
- 操作キー表示

## 6. スローとの関係

フィルター選択時の撮影・配置では集中補助としてスローが入ります。

- 撮影開始時: `0.8` 秒
- 配置開始時: `1.2` 秒
- シャッターフラッシュは通常速度

## 7. 実装場所

主に次を見ます。

- `components.h`
- `components.cpp`
- `game_scene.cpp`
- `game_scene_gameplay.cpp`
- `game_scene_render.cpp`

## 8. フィルターを追加・変更するときの確認

変更時は最低限これを確認してください。

- 元オブジェクト側の効果
- コピー側の効果
- UI 表示
- 撮影フレーム色
- 配置プレビュー色
- 敵との相互作用

片側だけ変えて終わると仕様が壊れやすいです。
