# Gimmick CSV Placement Guide

このドキュメントは、`assets/maps/**/*.csv` にマーカーを置いてギミック配置するための実務向けメモです。

## 1. 基本

- 1セル = 1グリッドです。
- マーカーは大文字で管理してください（エディター操作時も同じ）。
- 変更後はゲーム内で `F6` 再読込、またはシーン再起動で反映確認します。

## 2. ギミック系マーカー一覧

## 2.1 CSVセルの書き方（実例）

- マーカーだけ: `O`
- マーカー+パラメータ: `O2` / `J99` / `J-3`
- タイルと同時指定: `1|O2` または `1:O2`
- 空セル（0）にマーカーだけ置く場合は `O` でOK

例:

- `O2`: レーザースイッチ、リンクID=2
- `J2`: シャッター、移動量2タイル
- `J-2`: シャッター、リンクID=2
- `J99`: シャッター、ボス撃破トリガー有効
- `1|J2`: 地面タイルの上にシャッターマーカー

### `Y` バッテリー

- サイズ: `1x1`
- 用途: 持ち運び/落下ダメージ/スイッチ入力
- パラメータ: なし

### `K` バッテリースイッチ

- サイズ: `3x0.5`
- 用途: 同じリンクIDの昇降系を起動
- パラメータ:
- `> 0`: 必要バッテリー個数
- 未指定/`0`: `1`
- `K(*`: プレイヤーが上に乗っている間だけON。配置順リンクは通常の`K`と同じ
- `K2(J3`: 必要数 `2`、リンクID `3`。`J3` のシャッターなどを起動
- `K4(Q`: 必要数 `4`、最寄りの `Q`（4タイル幅エレベーター）を起動
- `K2(L`: 必要数 `2`、最寄りの `L`（5タイル幅エレベーター）を起動

### `L` エレベーター

- サイズ: `5x1`
- 用途: 同じリンクIDのスイッチ入力で動作
- 動作: 電源ON中にプレイヤーが触れると起動し、上端と下端で各3秒停止しながら自動往復
- パラメータ:
- `> 0`: 移動幅（タイル数）
- 未指定/`0`: `3`

### `U` レーザー砲台

- サイズ: 砲身 `3x1`（レーザーは砲身から右へ伸びる）
- 用途: レーザーで継続ダメージ、レーザースイッチ入力源
- パラメータ: なし

### `O` レーザースイッチ（LS）

- サイズ: `1x2`
- 用途: レーザーが当たっている間だけ `ON`。離れると `OFF`
- パラメータ:
- `> 0`: リンクID上書き
- 未指定/`0`: 配置順リンク

### `J` シャッター

- サイズ: `1x3`
- 用途: 起動フラグで上下する壁
- パラメータ:
- `> 0`: 上昇量（タイル数）
- `< 0`: リンクID上書き（絶対値）
- `99`: ボス撃破連動を有効化（リンクON または ボス撃破で開く）
- 未指定/`0`: 既定移動量 + 自動リンク

### `H` / `I` ダメージ足場

- サイズ:
- `H`: 横3タイル相当
- `I`: 横2タイル相当
- 用途: 触れるとダメージ
- パラメータ: なし

### `M` 丸太

- サイズ: `4x1`
- 用途: 物理で転がるオブジェクト
- パラメータ: なし

### `B` 樽

- サイズ: `1x1`（実体はプレハブ準拠）
- 用途: 物理オブジェクト
- パラメータ: なし

### `V` 撮ると消えるオブジェクト

- サイズ: プレハブ準拠
- 用途: キャプチャーで消滅するギミック
- パラメータ: なし

### `C` チェックポイント

- サイズ: プレハブ準拠
- 用途: 配置した縦列全体を通過判定にして、リスポーン地点を更新
- 表示: ゲーム中は透明
- 復帰位置: 判定した高さではなく、実際に `C` を配置した位置
- 同じ縦列に複数配置した場合: 一番下の `C` を使用
- 保存: 起動中のセッションだけ有効。ゲームを閉じて開き直すと解除
- パラメータ: なし

### `=` ステージ遷移

- 用途: `stage_transitions.csv` に設定した次ステージへ移動
- 表示: オブジェクト本体は透明で、マーカー右半分に出口を示す影のみ表示
- 遷移条件: プレイヤー中心が `=` のセルへ入る

## 3. リンクIDの考え方（重要）

- 連動は「同じリンクID」で判定します。
- `K/L/O/J` はリンクIDで接続されます。
- `O`（レーザースイッチ）に `linkId` 指定がない場合:
- 配置順のIDを使用します。
- `J`（シャッター）に `linkId` 指定がない場合:
- 最寄りの `O` を自動参照します。
- `K(J3` または `K2(J3` で、バッテリースイッチからリンクID `3` へ給電できます。

## 4. 代表パターン

### レーザーでシャッターを開く

1. `U`（砲台）を配置
2. レーザー線上に `O`（スイッチ）を配置
3. 開けたい場所に `J`（シャッター）を配置
4. 厳密に組みたい場合は `O` と `J` に同じリンクIDを設定

### バッテリーでエレベーターを動かす

1. `K`（スイッチ）を配置
2. `L`（エレベーター）を配置
3. 必要なら `K` で必要個数、`L` で移動幅を設定

### バッテリーでシャッターを開く

1. `K(J3`（必要数1）または `K2(J3`（必要数2）のスイッチを配置
2. `J3` のシャッターを配置
3. 必要数のバッテリーをスイッチへ載せると、リンクID `3` がONになりシャッターが開く

## 5. キャプチャー可否（ギミック関連）

- キャプチャー不可:
- `K` バッテリースイッチ
- `L` エレベーター
- `O` レーザースイッチ
- `J` シャッター
- レーザー本体（ビーム）

- 砲台 `U` は本体のみキャプチャー対象（ビームは対象外）

## 6. 配置チェックリスト

- レーザーがスイッチに実際に届いているか
- リンクIDの意図した組み合わせになっているか
- シャッター開時/閉時で進行不能が起きないか
- プレイヤー/敵/バッテリーが埋まらないか
