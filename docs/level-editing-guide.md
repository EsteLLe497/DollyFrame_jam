# Level Editing Guide

このドキュメントは、ステージや配置を触る人向けのルールです。  
目的は「どこをデータで触れるか」「どこからコード修正が必要か」を明確にすることです。

## 1. まず前提

このプロジェクトは、レベルが完全データ駆動ではありません。  
今は次の 2 つが混在しています。

- CSV / JSON で持っている部分
- `game_scene.cpp` に直書きしている部分

そのため、レベル編集は

- データだけで済む変更
- コードも触る変更

を分けて考えてください。

## 2. 主に触るファイル

- `assets/maps/side_scroll_stage01.csv`
- `assets/prefabs.json`
- `game_scene.cpp`
- `assets/tuning.json`

## 3. `side_scroll_stage01.csv`

役割:

- タイル地形
- 地面や危険帯、ゴール位置の目印

現在の主な値:

- `0`: 空
- `1`: 地面
- `2`: 足場
- `3`: 装飾床
- `4`: 危険帯の目印
- `5`: ゴール目印

### 向いている変更

- 地形の形
- 足場の高さ
- 危険帯の位置
- ゴール位置のベース調整

### 向いていない変更

- プレイヤー初期配置
- 敵配置
- `PhotoSource` 配置
- フィルター仕様

これらは今の実装ではコード側の方が強いです。

## 3.1 ゲーム内簡易マップエディター（F4）

現在は `GameScene` で簡易的なタイル編集ができます。  
ゲーム実行中に `F4` で編集モードに入り、同じキーで閉じます。

- 左ドラッグ: 選択タイルを塗る
- 右ドラッグ: タイルを `0`（空）に戻す
- `0-9`: タイル値を直接選択
- `Q / E`: タイル値を前後に切替
- `F9`: タイル `10`（奈落）を選択
- `M`: タイル編集 / マーカー編集を切替
- マーカー編集時:
- `0`: マーカーなし
- `1`: `G`
- `2`: `S`
- `3`: `E`
- `4`: `T`
- `5`: `W`（Walker）
- `6`: `R`（Ranged）
- `7`: `B`
- `8`: `V`
- `9`: `C`
- `F10`: `M`（丸太）
- `F11`: `Y`（バッテリー）
- `F12`: `N`（中ボス）
- `H / I`: ダメージ足場
- `J`: シャッター
- `K`: バッテリースイッチ
- `L`: エレベーター
- `O`: レーザースイッチ
- `U`: レーザー砲台
- `Q / E`: マーカー候補を前後に切替
- `F5`: 現在の CSV へ保存
- `F6`: CSV を再読込（破棄して読み直し）
- `F7`: 新規マップ作成（空マップ、現在サイズ）
- `F8`: 別名保存（現在マップをコピー保存）

注意:

- マーカー編集は `G / S / E / T / W / R / B / V / C / M / Y / K / L` をサポートしています。
- マーカー編集は `G / S / E / T / W / R / B / V / C / M / Y / H / I / J / K / L / O / U / N` をサポートしています。
- 敵マーカー（`W / R / N`）、バッテリーマーカー（`Y`）、エレベーター系マーカー（`K / L`）は、エディター中に置いた瞬間に配置へ反映されます。
- レーザー/シャッター系マーカー（`U / O / J`）も、エディター中に置いた瞬間に配置へ反映されます。
- ギミックの詳細配置ルールは `docs/gimmick-csv-placement-guide.md` を参照してください。
- 保存先は現在読み込んでいるマップ (`gCurrentMapCsvPath`) です。
- `F7` / `F8` で作成されるファイルは `assets/maps/stages` 配下に `new_map_YYYYMMDD_HHMMSS.csv` / `copy_map_...` 形式で出力されます。

## 4. `GameScene` の prefab 配置

現在の `GameScene` では、次の主要配置物を `assets/prefabs.json` の `sandbox_*` prefab から生成しています。

- プレイヤー
- ゴール
- `PhotoSource`
- `Hazard`
- 敵

配置座標そのものは `game_scene_setup.cpp` で決めています。  
つまり、ステージ上の主要なインタラクティブ要素を動かしたい場合は、

- 構成を変えるなら `assets/prefabs.json`
- 位置を変えるなら `game_scene_setup.cpp`

を見ます。

## 5. 配置するときのルール

基本はグリッド基準です。

- `tileSize` を基準に置く
- 1 マス、2 マス単位を意識する
- 位置はグリッドへ揃える

今の基準サイズ:

- プレイヤー: `1 x 2` マス
- ゴール: `2 x 2` マス
- 敵: `1 x 1` マス
- `PhotoSource`: `1 x 1` マス
- `Hazard`: `1 x 1` マス

## 6. 調整値

細かい感触は `assets/tuning.json` で変えられます。

例:

- カメラ幅
- ジャンプ速度
- 重力
- 撮影枠サイズ
- ボーナス時間

ただし、ルールの追加まではできません。

## 7. レベル担当がよくやる変更

### 地形だけ変えたい

見る場所:

- `assets/maps/side_scroll_stage01.csv`

### ゴール位置を変えたい

まず見る場所:

- `CSV` の `5`

必要なら見る場所:

- `game_scene.cpp`

### 敵の数や置き場所を変えたい

見る場所:

- `assets/prefabs.json`
- `game_scene_setup.cpp`

### `PhotoSource` の位置を変えたい

見る場所:

- `assets/prefabs.json`
- `game_scene_setup.cpp`

### フィルターで遊び方を変えたい

見る場所:

- `docs/filter-spec.md`
- `game_scene_gameplay.cpp`

## 8. レベル編集時のチェック

最低限これを確認します。

- プレイヤーが開始直後に埋まらないか
- ゴールに到達可能か
- 敵とギミックが重なっていないか
- 撮影と配置の導線が破綻していないか
- グリッドから大きくズレていないか

## 9. いまのレベル編集で注意すること

### 1. CSV だけ変えて満足しない

このゲームは写真システムが中心です。  
地形が成立していても、

- 撮る対象
- 貼る余地
- フィルターを使う余地

がないと遊びとして弱くなります。

### 2. 主要オブジェクトを半端な座標に置かない

背景グリッドとズレると、見た目も当たり判定も気持ち悪くなります。

### 3. 敵追加時はフィルター反応を見る

敵は今、

- `Hot`
- `Cold`
- `Invert`
- `Sepia`

に反応します。  
配置だけ見て終わらず、そこまで含めて確認してください。

## 10. 困ったとき

迷ったらまず次を分けてください。

- 地形を触りたいのか
- オブジェクトを置きたいのか
- ルールを変えたいのか

この 3 つが混ざると作業が重くなります。  
レベル担当の作業は、まず「配置」と「ルール変更」を分けるところから始めるのが安全です。
