# マップタイル テクスチャ・オートタイル説明書

この説明書は、マップごとにタイルテクスチャを切り替える方法と、マップエディターでのオートタイル操作をまとめたものです。

## できること

- ステージごとに使うマップタイルのテクスチャを変えられます
- マップエディターで新しく配置したタイルも、その場でオートタイル表示されます
- すでに配置済みのマップにも、読み込み時に自動で反映されます
- タイルシートは 3 x 3 の 9 分割で読み込みます
- 分割後の 9 枚は、すべて同じサイズとして扱います

## 使うテクスチャ

現在の実装では、主に次のテクスチャキーを使います。

- `tile_forest_ground`
- `tile_default`

ステージ用の 9 分割シートは `tile_forest_ground` を使う想定です。
`tile_default` は予備・フォールバック用です。

## 1. ステージごとにテクスチャを変える方法

各マップ CSV の先頭に、次のようなヘッダーを書きます。

```csv
# tileTexture=tile_forest_ground
1,1,1,1,1
1,0,0,0,1
1,0,1,0,1
1,1,1,1,1
```

この `tileTexture` が、そのマップで使うテクスチャキーです。

### 注意

- ヘッダーが無い既存 CSV は、読み込み時に既定のテクスチャが使われます
- 現在の既定は `tile_forest_ground` です
- CSV を保存すると、このヘッダーも一緒に書き出されます

## 2. マップエディターでの操作

### タイル配置

- 左ドラッグ: タイルを描く
- 右ドラッグ: タイルを消す

### タイル値の選択

- `0` - `9`: タイル値を直接選択
- `Q / E`: タイル値を前後に切り替え
- `F9`: タイル値 `10` を選択

### テクスチャ切り替え

- `PageUp`: 次のタイルテクスチャへ
- `PageDown`: 前のタイルテクスチャへ

切り替えたテクスチャは、現在のマップにすぐ反映されます。

### ファイル操作

- `F5`: 上書き保存
- `F6`: CSV を再読込
- `F7`: 新規マップ作成
- `F8`: 別名保存

## 3. 新規マップ作成時の挙動

`F7` で新しいマップを作ると、今選んでいるテクスチャキーを引き継ぎます。

つまり、エディターで `PageUp / PageDown` で切り替えたあとに新規作成すると、そのテクスチャ設定のまま新しい CSV が作られます。

## 4. 既存マップへの反映

既存のマップでも、読み込み時に次の順でテクスチャが決まります。

1. CSV の `# tileTexture=...` を読む
2. ヘッダーが無い場合は、既定で `tile_forest_ground` を使う
3. それでも見つからない場合は `tile_default` にフォールバックする
4. どちらも見つからない場合は白テクスチャで描画する

なので、古いマップでも再読込すればそのまま表示できます。

## 5. 9分割オートタイルの考え方

タイルは 3 x 3 の 9 マスに分割して描画します。
各マスは同じ大きさで、周囲 4 方向のつながりを見て、どのマスを使うかを自動で選びます。

### つながり判定

次のタイル値を「つながるタイル」として扱います。

- `1`
- `2`
- `3`
- `4`
- `10`

### 見た目の狙い

- 端のタイルは、周囲に合わせて角や縁の絵を出します
- ひとつだけ置いても、中央の絵になります
- 横や縦に伸ばすと、自然につながって見えます

## 6. つまずきやすい点

### 9分割シートなのに崩れて見える

- シートが本当に 3 x 3 で切れているか確認してください
- 9 枚の各タイルサイズがすべて同じか確認してください
- 途中に余白や別のサイズの絵が入っていないか確認してください

### テクスチャが切り替わらない

- マップエディターで `Tile` モードになっているか確認してください
- `PageUp / PageDown` は Tile モードで使います

### 保存したのに元に戻る

- `F5` で保存した CSV に `# tileTexture=...` が入っているか確認してください
- `F6` で再読込して、反映されたか確認してください

## 7. 新しいステージ用のテクスチャを増やしたいとき

新しいマップタイルを追加する場合は、次の 3 か所を触ります。

1. `assets/manifest.json` にテクスチャキーを追加する
2. `scenes/game/game_scene_map_editor_domain.cpp` の選択候補に追加する
3. 必要なら `scenes/game/game_scene_setup.cpp` のフォールバック順も調整する

## 8. ひとことで言うと

- マップごとのテクスチャは CSV の先頭で管理する
- エディターでは `PageUp / PageDown` で切り替える
- 保存すると設定も一緒に残る
- 9 分割シートは同サイズで自動オートタイルされる
