# チュートリアルCSV編集ガイド

表示内容は `assets/tutorials/tutorials.csv` で一括管理します。
画面座標、文字サイズ、フェード速度などのレイアウト設定は、従来どおり
`assets/ui_tuning.json` で管理します。

## 列

| 列 | 用途 |
|---|---|
| `tutorialId` | マップの`~番号`と対応する`tutorial_番号` |
| `order` | 表示順。小さい値から再生 |
| `type` | `conversation`（会話）または `window`（説明画面） |
| `speaker` | 会話の話者名 |
| `portraitPath` | 会話の立ち絵画像パス |
| `title` | 説明画面のタイトル |
| `text` | 会話文または説明文 |
| `confirmText` | 最終説明ページの閉じるボタン名。空欄時は「閉じる」 |
| `contentTextureKey` | `assets/manifest.json` に登録した説明画像のキー |
| `contentVideoPath` | 説明画像領域へ表示する動画パス。指定時は動画を優先 |

## 記述ルール

- 文章内の改行は `\n` と記述します。
- カンマを含むセルは `"..."` で囲みます。
- セル内の `"` は `""` と記述します。
- 同じ `tutorialId` の行は `order` 順に表示されます。
- マップの `~1` は `tutorial_1`、`~2` は `tutorial_2` を表示します。
- 番号なしの `~` は旧マップ互換として `~1` 扱いです。
- すべての `~番号` の検知範囲は、配置セルから右へ3マスです。
- 会話を増やす場合は `conversation` 行を追加するだけです。
- 会話ページの進行待ちはアイコン表示のため、`confirmText` は使用しません。
- 説明ページが複数ある場合は、左右キーまたは `A` / `D` で切り替えます。
- 動画はページ表示中に無音でループ再生され、縦横比を維持して中央表示されます。
- 動画が未指定、または読み込めない場合は `contentTextureKey` の画像を表示します。
- `#` から始まる行はコメントとして読み飛ばされます。

たとえば、ボス戦前に二人が会話してから操作説明を表示する場合も、
`conversation` を2行、`window` を1行の順に並べれば同じ仕組みを使えます。

デバッグUIの「チュートリアル」内にある「CSVを再読込」で、
ゲームを再起動せず編集結果を確認できます。
