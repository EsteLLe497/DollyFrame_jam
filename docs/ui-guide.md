# UI担当ガイド

このガイドは、HUD、メニュー、ラベル、画面内の情報表示を触る担当者向けです。

## まず知っておくこと

- このプロジェクトの UI は、専用 UI システムに閉じているわけではなく、各シーン描画に寄っています
- `GameScene` の UI は主に `game_scene_render_ui.cpp` にあります
- 見た目だけでなく、入力やゲーム進行との関係も確認が必要です

## まず見るファイル

- `game_scene_render_ui.cpp`
- `game_scene_render.cpp`
- `title_scene.cpp`
- `result_scene.cpp`
- `imgui_manager.cpp`

## よくある作業

### ゲーム中 HUD を直す

- `game_scene_render_ui.cpp` で描画位置と色を確認する
- プレイヤーが今必要な情報だけを出す
- 写真、残り時間、フィルター、危険状態などの優先順位を考える

### タイトルやリザルトの表示を直す

- 各シーンの描画処理を見る
- 入力導線が見えるかを確認する
- 見た目だけでなく、次の操作が伝わるかを見る

## このプロジェクトの UI で重要なこと

### 情報の優先順位を崩さない

特に `GameScene` では、

- プレイヤー位置
- 撮影範囲
- 現在フィルター
- 配置プレビュー
- 危険物

が重要です。これらを埋もれさせないようにします。

### フィルター状態は分かりやすく

- `None` は白
- `Hot` は赤
- `Cold` は青
- `Invert` は反転感のある中立色
- `Sepia` は茶系

のように、見ただけで区別できる状態を保ちます。

### デバッグ表示と本番 UI を混ぜすぎない

- ImGui で見る情報
- プレイヤー向け HUD

は役割が違います。デバッグ向けの数字をそのまま本番 UI に持ち込まないようにします。

## 作業時の注意

- 文字が背景グリッドに埋もれていないか
- 色だけに頼らず、ラベルや位置でも分かるか
- スロー中や撮影中に視認性が落ちていないか
- スクリーン端に寄りすぎて切れていないか

## 作業後チェック

- プレイしながら読めるか
- 撮影中と配置中で情報が足りているか
- 新しい UI が既存入力説明と矛盾していないか
